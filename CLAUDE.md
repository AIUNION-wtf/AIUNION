## Shell gotchas (learned the hard way)

- **PowerShell heredocs inside git commit**: `@'...'@` heredocs break when passed to `git commit -m`. Use single-line `-m "message"`, or write the message to a temp file and use `git commit -F path/to/msgfile`.
- **Env vars**: Set in-session with `$env:VAR="value"`, NOT `export VAR=value`.
- **Pipeline chaining**: PowerShell 5.1 does not support `&&` or `||`. Use `; if ($?) { ... }` for conditional chaining.
- **Emoji in Python print()**: Crashes the Windows console codec (cp1252). Either set `$env:PYTHONIOENCODING="utf-8"` before running, or use plain ASCII labels like `[WARN]` / `[OK]` / `[ERR]` in print statements.
- **Compound `cd` commands**: Require manual approval in Claude Code — that is expected behaviour, not a bug. Approve them.
- **Elevated vs. non-elevated context**: Task Scheduler tasks should use `-RunLevel Limited -User "$env:USERNAME"` so user-scoped env vars (e.g. `AIUNION_SIGNER_PASSPHRASE`) are accessible. `-RunLevel Highest` breaks them.

## Payout / pricing conventions

- **Agent proposal amounts**: Based on estimated LLM token cost and work scope — NOT a percentage of treasury balance. Tiers: small $1, medium $2–3, large/complex $4–5 (coordinator prompt guidance; separate from bounty display tiers below).
- **Bounty display tiers**: small $5–25, medium $25–100, large/complex $100–500.
- **Pro bono mode**: When `treasury.balance_usd < 10.0`, open bounties without an active checkout or pending claim display as `pro_bono: true, amount_usd: 0`. Bounties with an active checkout or a claim in `pending_review` always display at their `frozen_amount_usd`.
- **Payout amount**: Always `frozen_amount_usd / live_btc_price` at the moment of signing — the claimant receives the frozen USD value in BTC at current rates. No exchange rate is stored at checkout time.
- **Pre-checkout-era artifacts**: Payout artifacts written before the checkout flow existed lack `pro_bono` and `frozen_amount_usd`. Safe fallback: `pro_bono=False`, `frozen_amount_usd=amount_usd` from the artifact.
